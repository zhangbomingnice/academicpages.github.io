## 项目概述

面向铷（Rb）与铯（Cs）原子在复杂电磁场下的能级与跃迁计算场景，提出基于耦合强度的自适应基组截断算法，并将传统 ARC 3.0 原子物理仿真流程封装为可并发、可扩展的 SaaS 化计算平台，完成中国科学院大学科创计划项目交付。

## 主要工作与流程

- **自适应基组截断算法：** 面向 Rb/Cs 计算场景提出基于耦合强度的自适应基组截断算法，在有限云资源下提升多用户并发响应与计算吞吐量，并将数值收敛精度由 10⁻¹ 提升至 10⁻² 量级。

- **异步任务与部署：** 结合异步任务处理管线与 Docker 标准化部署流程，保障多用户并发使用时的稳定性与可维护性。

- **前后端架构：** 基于 React + FastAPI 设计前后端分离架构，将底层高阶非线性物理算法封装为后端接口，构建交互式 Web 页面，实现对原子主量子数及外场强度等关键参数的动态输入与实时计算。

- **平台能力：** 支持跃迁波长、Stark Map 与相关系数等核心能力，已作为中国科学院大学「大创计划」项目顺利结项。
