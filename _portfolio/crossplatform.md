## 项目概述

独立主导并交付两款覆盖 iOS、鸿蒙以及安卓系统与 Web 端的应用，通过继承 Claude Code、Opencode 等搭建 App 开发工作流，实现业务逻辑在多端的高效同步和迭代；从 UI 设计、3D 视觉渲染到后端数据库完成全栈开发，并在项目周期内探索 AI 工具链在交付过程中的辅助提升，具备多端产品从 0 到 1 的完整交付能力。

## 主要工作与流程

- **多端覆盖：** 覆盖 iOS、鸿蒙、安卓系统及 Web 端，实现业务逻辑在多端的高效同步与迭代。

- **开发工作流：** 通过继承 Claude Code、Opencode 等工具搭建 App 开发工作流，提升开发与交付效率。

- **全栈实现：** 从 UI 设计到 3D 视觉渲染再到后端数据库，完成完整系统的开发。

- **AI 工具链：** 在项目周期内探索 AI 工具链在交付过程中的辅助提升，具备多端产品从 0 到 1 的完整交付能力。
